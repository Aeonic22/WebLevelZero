
# General description of app

App is called "Neda". It is to be a hello world app with a db backend and a very simple crud logic. We are building a prototype, PoC, to be used only within my family.

It is to be developed in the simplest possible way, with no fuss about the intricate UI. Pure html / js app is also ok. On the mobile, it should be able to open from the icon on the home screen. DB can be any free online solution, but that is also useful for me to learn, such as Firebase.

It is indended to be used inside a family of 2 or more. 

# Authentification and authorization (AA)

Each user is identified by the backend using a passkey or a device id. AA should be simple to setup, and permanent.
